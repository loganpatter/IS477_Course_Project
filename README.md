Project Title: Relationship Between Crime, Median Household Income and Unemployment Rate in Texas Counties

Project Contributors: Logan Patterson

Summary: The overall goal of this project was to explore publicly available data amongst several Texas counties in order to determine what kind of relationship existed, if any, between the crime rate of the area and the median household income and unemployment rate of the same area. Texas has some of the best publicly available data portals of any state in the US, which was the main motivation behind using the datasets seen in this project. In regards to median household income being a financial factor examined, I figured this number would give a quick snapshot of the overall income levels of an area, but won't skew easily like average household income might. Unemployment rate was chosen since I figured the higher the unemployment rate, the more likely individuals may turn to crime to make up for a lack of income. I looked at the counties of Harris, El Paso, Austin and Dallas in specific in this project for no reason other than the fact that these were counties I had heard of in the past, so I figured most other people who interact with this data will have heard of at least one of them as well. The driving research questions for this project were as follows:

Research Question 1: What kind of relationship exists, if any, between the unemployment rate and crime rate of an area?

Research Question 2: What kind of relationship exists, if any, between the median household income and crime rate of an area?

To understand the economic factor data, I first used the requests library in Python to pull the specific datasets directly from the FRED API with my API key, as well as the specific series ID that was linked to the dataset I wanted to pull. Once this data was pulled and converted into a JSON file structure, I used the Pandas library to convert it to a Pandas DataFrame (df) for easier manipulation and analysis. Once these datasets were in the df form, I removed unnecessary columns (realtime_start & realtime_end) and added a county identifier column since I intended on combining all of these separate series into one large economic indicator dataset. After these preprocessing steps were completed I used the Pandas library to combine each of the two economic indicators for all 4 counties (8 total smaller datasets) into one large dataframe with 4 columns: Date, Med House Income, Unemployment Rate and County.

For the High Value Dataset from the TODP, which includes the currently incarcerated inmate population with relevant demographic, offense, and parole information in the state of Texas, I downloaded the dataset directly from the TODP as a CSV file. I was then able to use Pandas to pull the CSV in to my python notebook and convert it to a dataframe. I then removed unnecessary identifying information such as SID Number, TDCJ Number, Name and Case Number to create as ethical of a dataset as I could. Upon further inspection of the original dataset, I noticed there was a large amount of variation in the column 'TDCJ Offense' which describes the crime commited by the individual. Most of the other columns had stringent formatting requirements, but this one was left largely up to the discretion of the officer who input the information into the database. To best rectify this issue I used OpenRefine's clustering functions to attempt to cluster similar offense types (for example AGG, AGGR and AGGRAVATED) into one offense type to better aid analysis efforts. With this new CSV again pulled into python as a dataframe through Pandas, I was able to begin exploring and visualizing the data. I decided to examine two different 'crime types', the first including violent or sexual crimes (items such as aggravated crimes, murder, kidnapping, sexual assault and any kind of slaughter were included) and the second involving crimes related to theft (robberies, burglaries and crimes described as stealing or theft). It should be noted that any crime types that included violent keywords as well as theft keywords were included in both the violent and theft subsets. 

With my final exploration datasets and subsets created, I was able to visualize trends over time between both economic indicators and both crime types. Results will be further discussed in the results section of this report. 

Data Profile: 

Unemployment Rate data was provided by the U.S. Bureau of Labor Statistics via the FRED API, falling into the Public Domain of free use. Each of these datasets does request the usage of a citation, which will be provided in the references section. These datasets could either be queried as monthly or yearly aggregates of data, and I chose to examine yearly trends instead of monthly ones to allow for a more longitudinal examination of observations. The original datasets when first pulled from the FRED API included the following columns: realtime_start, realtime_end, date and value. Realtime_start and realtime_end simply display the date the data was accessed by the user, so I removed these unnecessary columns. The date column contained a year-month-day object which I converted into a datetime object to create time series graphs later in the analysis pipeline. I also renamed the 'value' column to the correct economic indicator, which in this case was 'Unemployment Rate'.

Estimate Median Household Income data was provided by the U.S. Census Bureau also via the FRED API, which also falls into the Public Domain. These datasets also ask for a citation, which will be in the references. These datasets could either be queried as monthly or yearly aggregates of data similarly to the above datasets, so I similarly chose to query yearly observations to match my choice above. The original datasets when first pulled from the FRED API included the following columns: realtime_start, realtime_end, date and value. Realtime_start and realtime_end were, again, unnecessary and removed. The date column was converted to a datetime object. The 'value' column was renamed to 'Med House Income' to indicate this was the median household income, in dollars, for the year in the specific county.


As all of these datasets fall within the public domain of free use and are widely available on the internet, I have no reservations about the usage of this data for exploratory data analysis. There is no identifiable information about specific persons or groups within the dataset, and the people who provided this data already gave consent to the Federal Government to collect, analyze and report said data to the public.
